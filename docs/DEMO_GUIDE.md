# Five-minute demo guide

1. Open the Dashboard and explain the three simulated systems.
2. Open Demo Simulator and create an order using Successful delivery.
3. Create another order using Missing required order_id.
4. Open Events and inspect the request payload and HTTP 400 response.
5. Open AI Investigations and generate an explanation.
6. Open Retries and retry the failed event.
7. Return to Dashboard and Reports to show the updated metrics.

Be explicit that the business applications and payments are simulated. The HTTP communication, payload validation, persistence, event history and retry logic run in the application.
